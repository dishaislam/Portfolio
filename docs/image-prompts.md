# Image prompts for utsho offerings

Save each image as `public/images/offerings/<slug>.webp` (or .jpg/.png). It appears on the home page automatically. Recommended size: 1200 x 800 px (3:2).

**Shared style (add to every prompt):** clean modern product mockup, soft natural light, calm navy and slate palette with one warm accent, minimal background, high detail, no text, no logos, no watermarks, 3:2 landscape.
